# Investment Research Skills

个人投研 Skill 仓库，用于保存和持续迭代投资研究工作中使用的 AI Skills。

## Skills

初步认知阶段
- `company-quick-understanding`：公司快速认知框架（主要结合三板斧）
- `financial-peer-comparison`：公司主要财务指标与可比公司对比

深入研究阶段
- `company-history-research`：公司历史研究
- `expert-interview-reading`：专家访谈纪要优先级排序
- `quick-research-report-reader`：快速阅读研报

跟踪
- `consumer-feedback`：消费者反馈归纳
- `product-experience-comparison`：不同产品消费者反馈横向对比

其他日常工作
- `meeting-recording-transcription`：会议纪要转写
- `meeting-summary`：会议纪要纲要撰写


每个 Skill 保存在独立文件夹中的 `SKILL.md`。后续修改直接更新原文件，由 GitHub Commit 历史保留版本变化。
