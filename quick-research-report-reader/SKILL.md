# 快速阅读研报 Skill

## Description

快速阅读并提炼单篇券商研报，用不超过300字的精简语言呈现最重要的信息，使读者无需阅读全文即可理解研报的核心判断、关键逻辑、盈利预测、估值方法、市场分歧及主要风险。

## Instructions

阅读用户提供的单篇研报，仅依据研报本身进行提炼，不得补充研报未提供的信息。

### 1. 核心结论

优先提炼作者最重要的投资判断，包括：

* 对公司、行业或业务趋势的核心判断
* 支撑判断的主要逻辑
* 最关键的数据或事实
* 作者认为最重要的增长驱动或变化因素

删除背景介绍、常识性内容、重复论述和低信息量描述。

不要按照研报原文顺序机械摘要，应按照信息重要性重新组织。

### 2. 盈利预测与估值

若研报提供盈利预测或估值，应保留最关键的信息，包括：

* 主要盈利预测
* 采用的估值方法
* 估值倍数
* 估值对应年份
* 目标价
* 当前价格对应的估值水平，如研报明确提供
* 选择该估值方法或估值倍数的依据

如果研报采用多个估值方法，只保留对最终目标价最重要的方法。

若研报未给出目标价、估值倍数或明确估值依据，应直接说明，不得自行推算。

### 3. 市场分歧

重点识别研报与市场共识、主流预期或普遍担忧存在明显不同的观点。

优先回答：

* 市场通常如何看
* 研报作者哪里看得更乐观或更谨慎
* 作者为什么认为市场存在误判
* 支撑这一分歧判断的主要证据

只有研报正文明确体现市场预期或市场分歧时才输出。

不得自行假设市场共识。

### 4. 潜在风险

风险分为两类：

**研报明确提示的风险**

提炼风险提示部分最重要的风险，不必完整复制全部标准化风险条款。

**正文隐含的关键不确定性**

如果正文中有充分证据表明某一因素可能削弱核心投资逻辑，可以将其列为风险。

例如：

* 核心增长假设未兑现
* 盈利改善依赖较强假设
* 竞争明显加剧
* 渠道、价格或需求变化
* 扩张效果低于预期
* 估值依赖较高增长预期

不得脱离研报内容自行创造风险。

### 5. 真实性要求

严格遵守以下规则：

* 不补充研报之外的信息
* 不根据常识推测作者观点
* 不夸大原文结论
* 不把可能性描述为确定事实
* 不虚构数据、估值、市场共识或风险
* 无法确认的内容明确说明
* 重要数字应与研报原文一致

如果研报没有覆盖某项内容，可以省略，不为保持格式完整而强行补充。

## Output Format

总字数控制在300字以内，采用分点形式。

### 核心结论

* 2至4条，只保留最重要的判断、逻辑和数据。

### 盈利预测与估值

* 简要说明盈利预测、估值方法、对应年份、估值倍数、目标价及依据。
* 未披露则明确说明。

### 市场分歧

* 只保留最重要的1至2项分歧及其依据。
* 无明确分歧则省略。

### 潜在风险

* 提炼2至4项真正可能影响核心逻辑的风险。

## 核心原则

目标不是“总结完整”，而是“保留最有投资价值的信息”。

在300字限制下，信息优先级依次为：

1. 作者最重要的核心判断
2. 支撑判断的关键证据
3. 盈利预测与估值逻辑
4. 与市场共识不同的观点
5. 可能推翻或削弱核心逻辑的风险

如果内容过多，应优先删除背景信息和次要细节，而不是压缩关键结论和估值逻辑。
